# Vali — Intelligent Day Planner & Flow State App

Vali is an intelligent, high-performance daily planner and productivity app designed to turn chaotic to-do lists into calm, focused momentum.

Built with a modern, high-converting SaaS landing page featuring fluid Framer Motion-grade animations, interactive 3D Bento grids, a 3D cylindrical community arc carousel, bi-directional scrolling testimonial marquee, interactive pricing toggle, and zero-dependency vanilla web tech.

---

## ✨ Features & Architecture

- **Hero Experience**: Floating levitation mechanics, diagonal phone gloss sweep animation, and spring-driven magnetic CTA buttons.
- **Bi-Directional Scrolling Testimonials**: Dual-row infinite marquee scrolling in opposite directions with edge gradient masks and hover-pause capability.
- **Interactive 3D Bento Grid**: Real-time cursor spotlight gradient tracking and 3D perspective tilt physics.
- **Visual Timeblocking & Scheduling**: Drag-and-drop calendar integration preview with zero double-booking friction.
- **Focus Shield & Pomodoro Sprint**: 25-minute focus session mode with ambient soundscapes and distraction silencing.
- **3D Cylindrical Arc Community Carousel**: Revolving 3D photo cylinder with momentum inertia drag and click-to-center physics.
- **Interactive Pricing Tier**: Monthly / Annual billing frequency switch with animated price transitions, discount pills, and smart scroll pulse highlight.
- **Interactive FAQ Accordion**: Expandable, single-focus accordion with rotating indicators.

## 🚀 Getting Started

Clone the repository and serve locally:

```bash
git clone https://github.com/Stevingfelix/Vali.git
cd Vali
```

Run a local HTTP server:

```bash
# Python 3
python3 -m http.server 8085

# Or Node.js npx
npx serve .
```

Open `http://localhost:8085` in your browser.
